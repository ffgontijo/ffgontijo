## Main Project

### GM Shield

**GM Shield** is a modular digital toolkit for tabletop RPG game masters.

The goal is to create a clean, scalable, and well-documented framework for organizing rules, references, tools, and system-specific resources. The project is designed to support multiple RPG systems while keeping the structure easy to expand and maintain.

This project combines two things I care about: **good technical organization** and **creative tabletop RPG design**.
